# 塑形机

<BlockImage id="lazy:shaper" scale="1.15" />

塑形机在不消耗材料与能量的前提下转换同种材料的常见形态。把想要的形态放进幽灵样品槽，再将粒、锭、宝石、粉、粗矿、板、杆、线、齿轮或储存块放入任意一条输入线。

<Recipe id="lazy:shaper" />

每条输入线最多容纳 1,024 件物品。机器按最小的无损整数交易即时换算：九粒变成一锭，一锭变成九粒，一板变成两杆。凑不满一笔交易的物品会原样留在输入线中。

八条输出线由全部输入共享；相同产物会优先合并，再占用空槽。输出池装不下一笔完整交易时，机器正面会显示堵塞状态，直到腾出空间。

样品属于设置而非存储。手持物品点击会选择形态但不消耗物品，空手游标点击则清空样品。拆除机器后样品会重置，输入与输出内容会随掉落的机器物品保留。

通过 [IO 与自动化](io.md)设置侧面输入、自动输出和网络输出。JEI 会以每种材料的一种基准形态为中心列出无损换算。整合包可以扩展会同步到客户端的 `lazy:material_form` 数据包注册表，也可使用塑形机黑名单标签关闭不安全的输入或输出。
