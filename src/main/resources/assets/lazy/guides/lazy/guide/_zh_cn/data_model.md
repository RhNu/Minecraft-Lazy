# 数据模型

<ItemImage id="lazy:data_model" scale="1.4" />

数据模型保存一个受支持的生物，作为模拟目标。

## 操作

- 使用空白模型点击受支持的生物，将其绑定到模型。
- 潜行使用已绑定的模型，清除其中的目标。
- 玩家以及被模拟规则拒绝的实体无法绑定。

将已绑定的模型放入模拟室的目标槽。模拟室会使用模型中保存的实体类型，不需要刷怪蛋或其它实体载体。
