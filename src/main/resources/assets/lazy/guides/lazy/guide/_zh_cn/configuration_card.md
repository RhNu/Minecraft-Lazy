# 配置卡

<ItemImage id="lazy:configuration_card" scale="1.4" />

配置卡保存一份完整的 Lazy 机器 IO 配置，可以重复用于所有兼容的机器。

## 操作

- 右键机器，将卡片中的配置应用到机器。
- 潜行右键机器，将机器当前的 IO 配置复制到卡片。
- 手持卡片右键空气，直接打开卡片的 IO 面板。
- 携带已配置的卡片放置机器时，新机器会继承该配置；空白卡片不会参与此过程。

## 保存内容

卡片保存 IO 模式、六个相对面的配置、自动弹出设置和选中的网络目标。网络目标属于卡片的链接数据，因此可以把卡片带到其它机器旁，而不必先打开原机器。

如果身上有多张配置不同的卡片，放置机器时不会自动选择其中一张；请直接将目标卡片应用到机器。
