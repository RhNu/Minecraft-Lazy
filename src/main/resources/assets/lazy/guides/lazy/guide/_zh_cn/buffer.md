# 缓冲器

<BlockImage id="lazy:buffer" scale="1.15" />

缓冲器是同时支持物品和流体的大型存储机器，可作为本地缓存，也可作为机器之间的交接点。

## 存储

- 8 个物品槽，每槽锁定一种物品，最多存放 256 个。
- 4 个流体罐，每罐锁定一种流体，最多存放 64,000 mB。
- 两套库存都会向相邻方块暴露能力；物品槽还支持在机器界面中正常点击、拆分、拖放与 Shift 点击交互。

右键打开界面；潜行右键只在动作栏报告物品和流体总量，不打开界面。清空按钮在确认后会销毁全部内部内容。

## 自动化

缓冲器通过通用的 [IO 设置](io.md)接收和输出物品、流体。破坏或用扳手拆除时，内部内容会保存在掉落的机器物品中。
