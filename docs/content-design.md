# 内容设计

## 定位

Lazy 是不考虑平衡性的工具箱。本文件只维护内容的产品定位、实现状态和玩家可感知契约，不复制注册参数、配置键、配方、资源 ID 或内部存储结构。

状态含义：

| 状态 | 含义 |
| --- | --- |
| 已实现 | 当前源码和资源已提供该内容 |
| 设计中 | 方向已进入讨论，但尚未形成运行时承诺 |

只有确认后的内容才能进入运行时代码、资源与 DataGen。

## 基础工具

| 内容 | 状态 | 定位 | 玩家可感知契约 | 代码归属 |
| --- | --- | --- | --- | --- |
| 传送器与虚空维度 | 已实现 | 在常规世界与虚空落点之间往返 | 传送失败不提交位置变化；只在允许的虚空目标处补安全落脚点 | `runtime/feature/teleporter`、`runtime/feature/voidworld` |
| 能量电池 | 已实现 | 随身无限 FE 抽取源 | 可被兼容容器接收，也可主动向点击目标传输 | `runtime/feature/energy` |
| 配置卡 | 已实现 | 复制机器 IO 设置并承载网络目标 | 应用配置不复制机器真实内容 | `runtime/core/io` |
| 模块化配置器 | 已实现 | 为 Integration 提供材料与模块化配置载体 | 模块数据相互隔离，物品内容由服务端保存 | `runtime/core/configurator` |
| 处理核心 | 已实现 | 为处理机器提供通用等级输入 | 每台机器自行解释等级带来的效果 | `runtime/feature/machine` |

传送状态与安全落点约束见 [传送规格](spec/teleportation.md)。

## 机器

| 内容 | 状态 | 定位 | 核心交互 | 特殊约束 |
| --- | --- | --- | --- | --- |
| 缓冲器 | 已实现 | 大容量物品与流体中转 | 通过能力、界面和 IO 系统访问内容 | 服务端存储是唯一事实源 |
| 能量源 | 已实现 | 无限 FE 方块源 | 被动抽取、面输出或网络输出 | 不伪装成有限储能机器 |
| 物品复制器 | 已实现 | 按模板持续产生物品 | 幽灵模板决定产物，输出无需真实库存 | 未接受的副本不缓存 |
| 修复器 | 已实现 | 服务器判定的物品耐久修复 | 放入物品后主动触发修复 | 第三方装备修复由独立 Integration 补充 |
| 模拟室 | 已实现 | 将目标、工具和处理核心解析为可持续模拟作业 | 随机结果进入统一大数输出仓 | 活动作业快照与待提交结果可恢复 |
| 塑形机 | 已实现 | 在同材料的不同形态间无损换算 | 幽灵样品选择目标形态 | 只执行可整除的最小整数交易 |
| 精华转换器 | 已实现 | Mystical Agriculture 精华档位换算 | 选择目标档后接收并输出精华 | 由对应 Integration 拥有 |

模拟室与塑形机的事务、背压和换算不变量见 [机器处理规格](spec/machine-processing.md)。所有使用统一 IO 的机器遵循 [IO 与网络输出规格](spec/io-and-network-output.md)。

## 玩家能力与命令

| 内容 | 状态 | 定位 | 服务端契约 | 代码归属 |
| --- | --- | --- | --- | --- |
| 上升命令 | 已实现 | 搜索当前位置上方的安全落点 | 搜索有界，传送前验证支撑、净空与世界条件 | `runtime/feature/rise` |
| 玩家保护 | 已实现 | 通过命令管理玩家级保护策略 | 附件持久化，伤害策略在服务端事件中执行 | `runtime/feature/protection` |

具体命令树和反馈文案由命令注册与本地化资源维护。

## 通用交互

| 领域 | 当前设计 |
| --- | --- |
| 朝向 | 机器以统一方向模型解释相对面配置 |
| 搬迁 | 真实内容可以随机器物品恢复；运行设置按机器契约处理 |
| 扳手 | 使用公共工具标签参与旋转与拆除交互 |
| 显示 | 正面世界显示只呈现识别与活动状态所需信息 |
| UI | 服务端持有事实状态，客户端只提交意图并显示同步结果 |
| 指南 | 玩家操作说明由 GuideME 的双语页面维护 |

## 视觉资产

| 层 | 约束 |
| --- | --- |
| 源文件 | `art/` 中的 SVG 是可编辑事实源 |
| 导出文件 | PNG 位于模组资源目录，通过 `renderArtTextures` 更新 |
| 机器外观 | casing 与机器职责 overlay 分层组织 |
| 玩家文本 | 所有可见名称、提示和反馈提供本地化资源 |
