# 传送规格

## 范围

本规格定义传送器菜单、玩家传送状态与安全落点的提交边界。封装空间的坐标、生命周期与删除事务见 [封装空间规格](encapsulated-spaces.md)。

## 状态与入口

外界返回点和最近选择的空间属于玩家附件，不属于传送器物品。附件可序列化并随玩家死亡复制；客户端只从打开的菜单获得显示所需快照。

| 入口 | 服务端校验 | 结果 |
| --- | --- | --- |
| 手持右键 | 手中是传送器、维度允许 | 打开传送器菜单 |
| Curios 快捷键 | 已装备传送器、维度允许、同 tick 去重 | 打开同一菜单 |

菜单请求只包含操作类型、空间 UUID 和改名文本。客户端不能提交坐标、所有者或空间状态；每次操作都在服务端重新校验权限、冷却、维度与空间状态。

## 路线与提交

| 操作 | 目标 | 玩家附件变化 |
| --- | --- | --- |
| 外界前往空间或 0,0 | 虚空维度内已验证落点 | 移动成功后保存出发位置；选择空间时同时保存其 UUID |
| 虚空内空间间移动 | 目标空间或 0,0 | 不覆盖外界返回点；选择空间时更新 UUID |
| 返回外界 | 已保存返回点，否则玩家重生点或主世界出生点 | 不清除返回点 |

同维度与跨维度移动均预加载目标区块。目标维度缺失、目标不安全或移动失败时不提交新返回点。成功移动关闭菜单并应用冷却；打开菜单、创建、命名和删除不应用冷却。

## 落点解析

落点搜索有界、确定且只读：

1. 按水平距离选择候选列。
2. 每列按接近请求高度的顺序检查候选位置。
3. 使用玩家碰撞尺寸验证支撑、净空、流体、危险方块、世界边界和建筑高度。
4. 找到第一个安全候选后结束。

空间目标只能在该空间的 15³ 净空中搜索；搜索失败不会修改空间。0,0 平台不安全时，前往中转站与依赖它撤离玩家的删除操作都会失败。

## 异常位置恢复

玩家登录或进入虚空时，服务端先保证中心平台已经执行过一次创建。位于已删除空间或未登记区域的玩家优先返回附件中的外界位置；该位置不可用时回退到玩家重生点或主世界出生点。

`/lazy rise` 在虚空维度始终拒绝，权限等级不能绕过。

## 测试边界

| 应验证 | 不固定 |
| --- | --- |
| 失败移动不提交外界返回点 | 序列化字段名 |
| 外界、虚空内与返回路线分别处理 | 冷却数值与反馈原文 |
| 空间落点搜索不越过净空 | 菜单视觉尺寸 |
| Curios 请求去重且不能提交坐标 | 第三方传送方式 |
| 异常虚空位置按附件与重生点恢复 | 世界中的普通建造行为 |
