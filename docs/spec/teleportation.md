# 传送规格

## 范围

本规格定义传送器的目标状态、落点解析和提交边界。虚空维度的注册数据、生成参数和配置范围由代码与资源维护。

## 状态模型

每件传送器独立保存外部返回点与虚空目标点。一次激活根据玩家当前是否位于虚空维度选择路线：

| 方向 | 请求目标 | 成功后更新 |
| --- | --- | --- |
| 进入虚空 | 已保存虚空目标，否则使用默认入口 | 保存当前外部位置与实际虚空落点 |
| 离开虚空 | 已保存外部返回点，否则使用默认返回点 | 保存离开前的实际虚空位置 |

请求目标与最终安全落点可以不同。只有跨维度移动成功后，最终落点才写回物品。

## 激活入口

| 入口 | 客户端责任 | 服务端责任 |
| --- | --- | --- |
| 手持使用 | 表达蓄力完成的使用意图 | 校验物品、维度、冷却并执行传送 |
| Curios 快捷键 | 发送无目标参数的激活请求 | 重新查找槽位物品并应用同一激活策略 |

客户端不能指定目标位置或提交传送器数据。同一玩家在切换维度期间或同一 tick 的重复快捷请求只执行一次。

## 落点解析

落点搜索是有界、确定且只读优先的过程：

1. 按水平距离选择候选列。
2. 在每列按接近请求高度的顺序检查候选位置。
3. 使用玩家真实碰撞尺寸验证支撑、净空、流体、危险方块、世界边界和建筑高度。
4. 找到第一个安全候选后结束搜索。

搜索顺序必须稳定，使相同世界状态与请求产生相同选择。搜索上界由运行时配置和实现常量共同限制，不能执行无界世界扫描。

## 安全平台

安全平台只允许在虚空目标且当前策略允许时创建。

| 阶段 | 行为 |
| --- | --- |
| 搜索现有落点 | 不修改世界 |
| 选择可清理候选 | 确认玩家身体空间和世界边界有效 |
| 创建平台 | 只替换可替换方块，并记录每个实际变化 |
| 再次验证 | 用与普通落点相同的安全规则检查结果 |
| 后续失败 | 仅回滚仍保持本次放置状态的方块 |

外部返回目标不创建平台。回滚不能覆盖传送期间由其他来源再次修改的方块。

## 提交顺序

| 顺序 | 操作 | 失败处理 |
| --- | --- | --- |
| 1 | 校验激活条件 | 不改变物品状态 |
| 2 | 选择路线并解析目标世界 | 不改变物品状态 |
| 3 | 解析安全落点，必要时准备可回滚平台变化 | 解析失败则回滚 |
| 4 | 执行跨维度移动 | 移动失败则回滚 |
| 5 | 写回传送器位置并应用成功冷却 | 只在移动成功后执行 |

失败反馈使用本地化 key；规格不维护具体文案或冷却数值。

## 测试边界

| 应验证 | 不固定 |
| --- | --- |
| 路线选择只更新对应端点 | 序列化字段名 |
| 搜索顺序有界、稳定并覆盖碰撞边界 | 平台材质与固定坐标 |
| 平台在验证或移动失败时安全回滚 | 配置文件原文 |
| 快捷请求去重且不能提交客户端目标 | 反馈文案原文 |
