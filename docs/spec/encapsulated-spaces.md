# 封装空间规格

## 几何与外壳

每个空间以一个锚点区块为定位基准。水平净空使用该区块两轴的 `min+1..min+15`，垂直净空为 `65..79`，因此可用区域严格为 15³ 且完全落在一个区块中。外壳为 17³，地板位于 Y=64，天花板位于 Y=80。

仅位于一个边界平面的方块使用半透明、自发光面板；同时位于两个或三个边界平面的方块使用白色实体边框。两者没有物品形态和掉落，不能被玩家、实体、爆炸或活塞移除。此保护只覆盖外壳，不构成领地保护。

## 坐标分配

空间锚点位于 1024 格网格，从 Chebyshev 半径 32 的方形环开始。分配序号先确定扩张环，再以与环周长互质、接近黄金比例的固定步长排列槽位，使早期位置交错覆盖象限。

| 不变量 | 约束 |
| --- | --- |
| 中心隔离 | 首个环距离世界中心至少 32768 格 |
| 空间隔离 | 最近外壁之间至少有 1007 个空方块 |
| 单调性 | UUID、序号和坐标删除后均不复用 |
| 有效性 | 登记前检查世界边界与已有外壳，失败仍消耗序号 |

## 持久化状态

主世界 `SavedData` 是全服事实源，保存下一分配序号、中心平台是否已创建，以及空间 UUID、所有者、可选名称、锚点区块、分配序号和状态。

| 状态 | 含义 | 启动恢复 |
| --- | --- | --- |
| `CREATING` | 已保留身份与坐标，外壳尚未确认完成 | 重新生成并激活；失败则清理登记与区域 |
| `ACTIVE` | 可列出、管理和传送 | 不修改 |
| `DELETING` | 删除事务已开始 | 继续清理，成功后删除登记 |

## 创建与删除事务

创建在服务端线程串行执行：登记 `CREATING`、加载外壳覆盖区块、清空内部并生成外壳，最后切换为 `ACTIVE`。创建失败会清理本次区域，但不会回收身份、序号或坐标。

删除重新校验所有权和状态后切换为 `DELETING`。若空间内有在线玩家，必须先解析安全的 0,0 撤离点；不能安全撤离任何玩家时不开始清理。成功撤离后，服务端丢弃区域内非玩家实体，以无掉落直接修改清除外壳、方块和方块实体，最后移除登记并释放区块票。

## 权限与菜单

普通玩家只能列出和管理自己创建的活动空间；权限等级 2 及以上的管理员可以管理全部空间并查看所有者。权限只约束列表、传送、命名与删除，其他方式进入后的建造和自动化不受所有权拦截。

默认显示名由 UUID 前八位无连字符字符生成，完整 UUID 只放在提示中。自定义名称去除首尾空白，长度为 1–32 个 Unicode 字符且不能包含控制字符；允许重名。删除必须使用显示名与短 UUID 二次确认。

每名玩家的活动空间数量受服务器配置限制，管理员绕过限制。空间创建不消耗材料或能量。
