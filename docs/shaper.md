# 塑形机

`lazy:shaper` 把同一材料的常见形态互相转换。全机只有一个不消耗的幽灵样品设置，用来指定目标形态；没有进度和能量。

## 共享资源仓

机器不再拥有“8 条并行线”，而是最多 8 种输入和最多 8 种产物的两个共享物品大数仓。相同物品按数据组件精确合并，每种数量使用正 `Long`。界面仍用两个 2×4 网格展示种类条目。

输出种类满时，只阻塞会创造第九种产物的输入；能合并到现有产物的其它输入继续加工。

## 换算

形态单位值仍以 1 锭 = 144 为基准。设输入单位值 `a`、输出单位值 `b`、`g = gcd(a,b)`：

```text
inputPerTrade  = b / g
outputPerTrade = a / g
trades = min(available / inputPerTrade, outputCapacity / outputPerTrade)
```

可用量、交易数和产量全部是 `Long`，乘法使用溢出检查。每个输入条目只做一次 O(1) 计算，并通过一个资源事务同时扣输入、加输出；不足一笔的余料留在输入仓。

## 每刻逻辑

运行时游标每刻轮转起点，公平检查最多 8 个输入条目。顺序为旧产物预输出、转换与原子提交、用剩余运输预算输出新产物、更新显示。工作量只与固定的 8 个种类条目有关。

样品是设置，不随机器掉落物保存。输入和输出使用 `resourcesIn` 与 `resourcesOut` 新 NBT 结构随机器搬迁；旧模板/计数数组不迁移。

被动 capability、面输出和网络输出都使用通用 `ResourceStore` 与 `StoredOutputSource`，不再保留机器专用仓或推送循环。材料形态注册表、黑名单、标签优先级和 JEI 辐射配方规则保持不变。
