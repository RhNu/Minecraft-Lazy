# 数据模型

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="lazy:data_model" scale="1.4" />
</Column>

数据模型可以保存一种生物，供[模拟室](simulation_chamber.md)使用。

## 操作

- 手持空白模型右键受支持的生物，将其绑定。
- 潜行右键使用已绑定模型，清除目标。
- 玩家和不支持的生物无法绑定。

把绑定后的模型放进模拟室目标槽即可。模型不会被消耗。
