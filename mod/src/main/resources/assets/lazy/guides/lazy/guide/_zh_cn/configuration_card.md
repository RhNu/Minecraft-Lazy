# 配置卡

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="lazy:configuration_card" scale="1.4" />
</Column>

配置卡可以复制并重复使用 Lazy 机器的 [IO 设置](io.md)。

## 操作

- 右键机器，应用卡片中的设置。
- 潜行右键机器，把机器设置复制到卡片。
- 右键空气，直接编辑卡片。
- 身上只有一种已配置卡片时，放置的新机器会立即应用该设置。

## 保存内容

卡片会保存模式、六个侧面、自动弹出和网络目标。

放置机器时会忽略空白卡片。身上有多种不同设置时，新机器保持默认状态；请直接使用想要的卡片。

安装 Curios 后，配置卡槽中的卡片也会参与自动配置和网络选择。
