# 塑形机

<BlockImage id="lazy:shaper" scale="8" />

塑形机在不消耗材料与能量的前提下转换同种材料的常见形态。把想要的形态放进幽灵样品槽，再将粒、锭、宝石、粉、粗矿、板、杆、线、齿轮或储存块放入共享输入仓。

<Recipe id="lazy:shaper" />

输入仓最多容纳八种精确物品身份，每种使用 Long 数量。机器按最小的无损整数交易即时换算：九粒变成一锭，一锭变成九粒，一板变成两杆。凑不满一笔交易的物品会原样留在输入仓中。

输出仓最多容纳八种精确产物；相同产物会优先合并，再占用空条目。某种身份堵塞时，仍可继续处理能合并到其它既有产物的输入。

样品属于设置而非存储。手持物品点击会选择形态但不消耗物品，空手游标点击则清空样品。拆除机器后样品会重置，输入与输出内容会随掉落的机器物品保留。

通过 [IO 与自动化](io.md)设置侧面输入、自动输出和网络输出。JEI 会以每种材料的一种基准形态为中心列出无损换算。整合包可以扩展会同步到客户端的 `lazy:material_form` 数据包注册表，也可使用塑形机黑名单标签关闭不安全的输入或输出。
