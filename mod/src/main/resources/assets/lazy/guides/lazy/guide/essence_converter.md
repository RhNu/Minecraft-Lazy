# Essence Converter

The Essence Converter is available when Mystical Agriculture is installed. It combines mixed essence into the selected tier.

## Target and conversion

- Select the target tier before inserting essence.
- The target cannot change while any essence or remainder is stored.
- Insanium is available when Mystical Agradditions is installed.

Different tiers can be mixed. The converter keeps any value that is too small to make one complete target essence. It stores up to 1,000,000,000,000 complete target essences by default.

## Output

- Insert essence through the input slot.
- Remove the selected tier through the output slot.
- The clear button destroys all stored essence.
- [IO settings](io.md) can send output to adjacent inventories or a supported network.

Removing Mystical Agradditions changes a saved Insanium target to Supremium without deleting the stored essence value.
