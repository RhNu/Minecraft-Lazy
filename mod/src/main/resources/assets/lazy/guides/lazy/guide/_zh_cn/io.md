# IO 与自动化

<ItemImage id="lazy:configuration_card" scale="1.4" />

支持物品、流体或 FE 的机器共用 IO 面板。机器内部的库存与产物离开机器的方式彼此独立。

## 模式

- **被动**：关闭主动输出；机器仍会向相邻方块暴露自己支持的能力。
- **面配置**：将每一面设为禁用、输入、输出或双向。启用自动弹出后，机器会把缓存产物推入标为输出的面。
- **网络**：将支持的产物发送到选定的网络提供者。提供者可以支持物品、流体、FE，或其中的组合。

侧面按钮以机器正面为参照。使用扳手旋转机器后，面配置会随新的朝向移动。

便携式 <ItemLink id="lazy:energy_battery" /> 的用法见[能量电池](energy_battery.md)页面。

## 配置卡

<ItemLink id="lazy:configuration_card" /> 保存完整的 IO 配置。右键机器应用配置，或潜行右键机器将配置复制回卡片；手持卡片右键空气可以打开同一套面板。

使用已经配置的卡片放置机器时，机器会从该配置开始运行。网络目标由卡片保持链接，机器不会保存运行时网络对象。

## 拆除机器

破坏机器时，机器内的存储内容会写入掉落的机器物品。机器只是替玩家暂存的物品（例如修复器中的输入物品）会单独掉落。使用扳手拆除时遵循相同规则。
