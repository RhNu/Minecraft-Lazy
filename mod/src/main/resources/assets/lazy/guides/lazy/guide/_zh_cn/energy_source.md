# 能量源

<Column alignItems="center" fullWidth={true}>
  <BlockImage id="lazy:energy_source" scale="8" />
</Column>

能量源提供无限 FE，每次传输最多提供 500,000,000 FE。

## 输出

- 相邻机器可以直接从中取用 FE。
- 面输出可以向指定方向主动供能。
- 网络输出可以把 FE 送入支持的存储网络。

右键打开 [IO 设置](io.md)。<ItemLink id="lazy:configuration_card" /> 可以复制或应用相同设置。
